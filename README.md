# Secondment countdown (Mon / Wed / Fri)

A single-page countdown of working days from 20 Oct 2026 to 19 Apr 2027, for someone who works Mondays, Wednesdays and Fridays.

- Counts only Mon / Wed / Fri, minus Hong Kong general holidays; tap the calendar to mark leave days.
- Today counts as a fraction of a 09:00-18:00 Hong Kong day, so the number ticks down through the day.
- Marked noindex / disallow-all for crawlers (a request, not enforcement).

Open `index.html` in a browser, or serve the folder with any static host.

Source: GovHK general holidays 2026/27.
